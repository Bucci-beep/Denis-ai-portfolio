DENIS AI PORTFOLIO: EXACT MAC STEPS

A. Download denis-ai-portfolio.zip to Downloads.
B. Double click ZIP to unzip.
C. Open Terminal and paste the following ONE command:

cd ~/Downloads/denis-ai-portfolio && npm install && npm run dev

Then open http://localhost:3000 in Safari.

If `npm: command not found`, install the LTS version of Node.js from https://nodejs.org and rerun the command.

To stop the server, press Control+C in Terminal.
To run again:
cd ~/Downloads/denis-ai-portfolio && npm run dev

To verify production build:
cd ~/Downloads/denis-ai-portfolio && npm run build

DEPLOY

Use GitHub Desktop to add this folder as a new repository, commit, and publish to GitHub. Then import the repository from Vercel (https://vercel.com/new). GitHub Desktop avoids writing git commands.
